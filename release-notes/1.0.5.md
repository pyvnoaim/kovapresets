### Sens in presets now actually applies

Sensitivity saved in a preset never took effect. It was written to a per-weapon
override that KovaaK's ignores unless you change it in-game — and worse, that
override then *shadowed* your real sens, so the preset's value did nothing even
after restarting.

Sens now goes through your global sensitivity, which means it applies **the next
time KovaaK's launches**. If you don't want to wait, the app tells you the exact
value so you can type it into KovaaK's own settings, which applies instantly.

**Your existing presets are migrated automatically** — nothing to rebuild. Any
preset that had a sens value will now start applying it, so it's worth checking
they're set to what you actually want.

### New: choose what happens after you apply a preset

Under Settings → **After applying a preset**:

- **Do nothing** — writes the settings and leaves the rest to you
- **Re-enter my scenario** — crosshair and sounds go live right away
- **Restart KovaaK's** — everything applies, sens and DPI included, and you land
  back in the scenario you were in (takes ~40s)

It only does as much as it needs to: a crosshair change re-enters your scenario
rather than paying for a full relaunch.

### Fixes

- Crosshair and sound presets no longer silently do nothing in scenarios whose
  weapon has a per-weapon override set in KovaaK's
- Sens and DPI now say plainly when they're waiting on a restart, instead of
  looking like they failed
- The "open KovaaK's settings for the theme" reminder no longer appears when a
  restart already applied the theme
- Preset details too long for the row now scroll into view instead of being cut off

### Removed

- **Start with Windows.** If you had it on, KovaPresets removes itself from
  Windows startup the first time you run this version.
