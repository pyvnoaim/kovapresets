### Updates now tell you they're ready

An update downloaded in the background, then said nothing. The only notice was a
toast in the app window — and the app spends most of its life in the tray, so the
toast painted into a window nobody was looking at, expired a minute later, and
never came back. 1.0.5 sat fully downloaded on a lot of machines without ever
mentioning itself.

There are now two places that hold onto it instead of one that flashes past:

- an **Update** button in the topbar that stays until you use it
- **Restart to update to …** in the tray menu, so you never have to open the
  window at all

The toast is still there, but it now waits until the window is actually visible
before spending itself.

This only takes effect from this version onward — the notice for an update is
given by the version you already have installed. If you're on an older build and
wondering where your update went: quit KovaPresets from the tray. Anything
already downloaded installs on quit, and always has.

### Sens applies reliably now

1.0.5 put sens on the route that works. It still didn't land every time, for two
reasons that both look like "it works sometimes".

KovaPresets checks whether KovaaK's is running on a timer, so for a few seconds
after the game started it still believed the game was closed. An apply in that
window wrote sens straight to the settings file — which a running game owns in
memory and overwrites — with nothing queued to put it back. Launching the game,
alt-tabbing out and clicking a preset lands in that window more often than not.
The check is now made fresh at the moment you apply.

The second one is quieter. A preset whose sens already matched the settings file
was treated as having nothing to do, so nothing was queued — and then the game's
own write on quit put its launch-time sens back. A preset now re-asserts what it
holds after the game closes, whether or not it looked like a change at the time.
